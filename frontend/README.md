# Затея — фронтенд

SPA-витрина платформы запуска геймифицированных промо-механик и мотивационных программ.
Работает полностью автономно: без бэкенда все данные отдаёт встроенный мок, живой рейтинг
крутит эмулятор. Реальные адреса подставляются через переменные окружения.

## Запуск

```bash
npm i
npm run dev      # http://localhost:5173
```

## Скрипты

| Команда             | Что делает                                          |
| ------------------- | -------------------------------------------------- |
| `npm run dev`       | Дев-сервер Vite                                    |
| `npm run build`     | Типизация (`vue-tsc`) + продакшн-сборка в `dist/`  |
| `npm run preview`   | Локальный предпросмотр собранной версии (порт 4173) |
| `npm run typecheck` | Проверка типов `vue-tsc --noEmit`                  |
| `npm run lint`      | ESLint (`@typescript-eslint`, `eslint-plugin-vue`) |
| `npm run format`    | Prettier                                           |
| `npm run test`      | Компонентные и модульные тесты (Vitest)            |

## Переменные окружения

Скопируйте `.env.example` в `.env`. Все переменные опциональны.

| Переменная              | По умолчанию | Назначение                                                             |
| ----------------------- | ------------ | -------------------------------------------------------------------- |
| `VITE_API_BASE`         | `/api/v1`    | Базовый адрес REST API                                              |
| `VITE_API_MOCK`         | `true`       | Мок-режим API. `false` — ходить в настоящий `VITE_API_BASE`         |
| `VITE_CENTRIFUGO_URL`   | —            | Адрес Centrifugo для живого рейтинга. Пусто — работает эмулятор     |
| `VITE_CENTRIFUGO_TOKEN` | —            | Токен подключения к Centrifugo                                     |

## Экраны

- **Витрина кампании** `/c/:slug` — как видит участник: герой с оформлением, период, баланс
  попыток, живой рейтинг (топ-10 + «моя позиция»), «Мои призы».
- **Игровой экран** `/c/:slug/play` — викторина (вопросы, прогресс, экран результата) и
  колесо фортуны (анимированное SVG-колесо секторов). Механики «собери набор» и «промокоды» —
  свёрстанные заглушки.
- **Кабинет организатора** `/admin` — список кампаний, создание/редактирование
  (`/admin/new`, `/admin/campaigns/:id/edit`), карточка кампании с вкладками «Сводка»,
  «Призы», «Промокоды» (`/admin/campaigns/:id`).
- **Каналы** `/channels` — веб, Telegram, VK; оформленное пустое состояние.
- **404** и пустые состояния оформлены.

Каркас: боковое меню с пиктограммами-метафорами разделов, шапка с логотипом и переключателем
«участник / организатор» (демо-режим).

## Стек

- Vue 3 (`<script setup>`, Composition API) + Vite + TypeScript
- Tailwind CSS 3, дизайн-токены — CSS-переменные (`src/assets/main.css`)
- `vue-router`, `pinia`
- Иконки — `lucide-vue-next`
- Живой рейтинг — обёртка над `centrifuge` с эмулятором-транспортом по умолчанию
  (`src/shared/realtime/`)
- Графики — инлайновый SVG без внешних либ (`src/ui/Sparkline.vue`)
- Тесты — Vitest + `@vue/test-utils`

## Мини-кит компонентов

`src/ui/` — собственные компоненты в единой стилистике, без внешних UI-китов:

`Button`, `Input`, `Select`, `Card`, `Badge`, `Table` (типизированный, generic),
`Tabs`, `Modal`, `Toast` + `ToastHost` (+ стор `useToasts`), `Progress`, `Avatar`,
`StatTile`, `Sparkline`.

## Слой данных

`src/shared/api/` — типизированные клиенты (`campaigns`, `participation`, `admin`) поверх
`apiRequest`. В мок-режиме запросы обслуживает `src/shared/api/mock/` с реалистичными
данными и изменяемым состоянием на время сессии. Контракт — `src/shared/api/types.ts`.
